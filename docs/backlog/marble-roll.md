## Notes

- **Potential first build** — technically simple, high viral potential
- Uses terrain elevation data from Mapbox to create the physics surface
- Marble is a procedural sphere — no assets needed at all
- Physics: cannon.js or rapier.js (WASM) integrated with R3F
- Core loop: user enters address → sees 3D terrain of their area → taps to drop marble → watches it roll downhill
- Could add multiple marble sizes, materials (glass, steel, rubber — different bounce/friction)
- Add trail effect behind marble for visual satisfaction
- Include "share your roll" button with screenshot of the marble path
- Low CPC but high shareability — this is a traffic magnet for the portfolio, not a direct earner
- Cross-promotes the useful configurators via the "You might also like" bar
