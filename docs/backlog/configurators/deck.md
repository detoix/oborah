## Notes

- **First site to build** — proves the entire engine end-to-end
- Cedar and composite are most popular in DE/PL markets
- Standard plank dimensions: 2.4m / 3m / 4.2m lengths, 140mm width, 28mm depth
- Post spacing: typically 1.2-1.5m
- Railing required by building code in most EU countries when deck height > 60cm
- Composite decking trending upward — include multiple composite options
- Include a "joist" layer that auto-generates substructure based on deck shape (advanced feature, phase 2)
